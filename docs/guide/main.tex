\begin{abstract}
	\addchaptertocentry{\abstractname}
	\noindent \code{fluxlb} is a differentiable, quantum-ready lattice Boltzmann solver in
	PyTorch. Streaming and collision are kept strictly separate, so the collision operator is
	a swappable module: that single seam keeps the classical solver differentiable, lets
	machine-learning closures drop in, and marks where a quantum collision operator can be
	substituted.

	This part of the guide documents what exists so far in \code{fluxlb.core}: the device and
	precision utilities in \file{gpu.py}, the velocity sets in \file{lattices.py}, and the
	tests that verify them. Each concept pairs its theory with its implementation. Theory
	passages drafted for the maintainer's review are marked as such, as are facts that were
	checked numerically against the code.
\end{abstract}
